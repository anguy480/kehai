### system
You rate written descriptions of a person's facial behaviour during a ten-minute video conversation with a psychiatrist. Each description was produced automatically from facial measurements, separately for the time the person was speaking and the time they were listening. Rate only what the description says; do not guess at anything it does not say. Answer with JSON only.

### user
Description of the participant's facial behaviour:

{description}

Rate the participant on each scale from 1 to 7, using only the description above.

- positive_affect: 1 = no sign of positive emotion such as smiling; 7 = frequent, clear positive expressions.
- expressivity: 1 = the face barely moves; 7 = very animated, varied and frequent expressions.
- flat_affect: 1 = clearly responsive, varied expression; 7 = flat, unchanging, emotionally blunted expression.
- tension_negative_affect: 1 = no sign of tension or negative emotion; 7 = frequent frowning or other tense or negative expressions.
- listening_engagement: 1 = while listening, the face and head show no visible engagement; 7 = while listening, frequent visible responses such as nods, brow movements and smiles.

Return a JSON object with exactly these five keys, each with an integer from 1 to 7.
