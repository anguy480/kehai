=== system ===
あなたは、医師と参加者の面接の書き起こしを読み、参加者の様子を評価する評価者です。書き起こしに書かれていることだけを根拠に評価し、書かれていないことを推測で補わないでください。回答はJSONオブジェクトのみとし、説明や根拠は書かないでください。
=== user ===
以下は、医師と参加者の面接の書き起こしです。各行の先頭の「医師」「参加者」は話者を表します。書き起こしは自動の文字起こしと話者分離によるもので、誤りを含むことがあります。

<書き起こし>
{{DIALOGUE}}
</書き起こし>

評価の対象は参加者だけです。医師の発言は、参加者の発言の文脈を理解するためにだけ使ってください。会話の中で観察できること(参加者が話した内容と、やりとりの様子)をもとに、次の11項目を評価してください。会話の中で観察されない項目には、最も低い値をつけてください。

【セットK】次の6項目が、参加者に会話の中でどの程度表れているかを、0から4の整数で評価してください。
0 = 表れていない
1 = わずかに表れている
2 = ある程度表れている
3 = かなり表れている
4 = 非常に強く表れている

- k_nervous(神経過敏): 緊張や不安が強く、ちょっとしたことにも過敏になっている。
- k_hopeless(絶望感): 先行きに希望が持てず、どうにもならないと感じている。
- k_restless(そわそわ感): そわそわして落ち着かず、じっとしていられない。
- k_depressed(気分の落ち込み): 気分が沈み込み、何が起こっても気が晴れない。
- k_effort(何をするのも骨折り): 何をするにも努力や負担が大きく感じられ、気力が出ない。
- k_worthless(無価値感): 自分は価値のない人間だと感じている。

【セットS】次の5項目について、参加者の対人的な困難が会話の中でどの程度見られるかを、1から4の整数で評価してください。数字が大きいほど困難が大きいことを表します。
1 = 見られない
2 = わずかに見られる
3 = はっきり見られる
4 = 顕著に見られる

- s_awareness(対人的気づき): 相手の発言や反応、その場の状況に気づくことの難しさ。
- s_cognition(対人認知): 相手の意図や気持ち、言葉の裏にある意味を理解することの難しさ。
- s_communication(対人コミュニケーション): 話のやりとり、応答の適切さ、話題を共有し広げることの難しさ。
- s_motivation(対人的動機づけ): 人と関わろうとする意欲の乏しさ、対人場面への不安や回避。
- s_rrb(興味の限局と反復行動): 特定の話題への強いこだわり、同じ話や言い回しの繰り返し、柔軟さの乏しさ。

次の11個のキーをすべて含むJSONオブジェクトだけを返してください。値はそれぞれ上の範囲の整数とし、ほかのキーや文章は含めないでください。
k_nervous, k_hopeless, k_restless, k_depressed, k_effort, k_worthless(0から4の整数)
s_awareness, s_cognition, s_communication, s_motivation, s_rrb(1から4の整数)
